## 简短说明

非官方本地工具，用于浏览、搜索、导出、归档和安全删除存储在你电脑上的
Claude Code 与 Claude Desktop 会话。与 Anthropic 无关。

## 说明

Claude Local Session Manager 是一款面向 Windows 上 Claude Code 和 Claude Desktop
用户的非官方桌面工具。它会找到这两个应用保存在你电脑上的会话文件，并以快速、
可搜索的列表显示——清晰呈现标题、项目、日期、大小以及每个会话对应的确切文件。

一切都在本地完成。本应用没有账户、没有服务器，不会将会话内容发送到任何地方，
也不收集遥测数据。

清理操作以安全为前提设计：
• 应用始终以安全模式启动，此时无法删除任何内容。
• 必须在当前会话中输入 ENABLE DELETE 才能启用永久删除，删除一次或 10 分钟后
  自动关闭。
• 每次删除都会显示将删除和不会删除的确切文件计划，并需要输入确认。
• 正在 Claude Code 中打开的会话，或 Claude Desktop 正在运行时，无法修改。
• 你的项目文件夹永远不会被触碰。

非官方本地工具。与 Anthropic 无关，未获得 Anthropic 认可或赞助。
"Claude" 是 Anthropic 的商标。

## 产品功能

- 自动查找 Claude Code 和 Claude Desktop 会话
- 按标题、提示词、项目、路径或会话 ID 快速搜索
- 按日期或项目分组；按日期、标题或大小排序
- 详情：标题、ID、模型、消息数量、文件和大小
- 归档 / 恢复 Claude Desktop 会话
- 在管理器中隐藏会话，不修改 Claude 的文件
- 导出为 JSONL、JSON 或可读的 Markdown
- 默认安全模式；永久删除需启用、一次有效，并显示确切计划
- 存储概览：最大的项目和会话
- 界面支持 English、Tiếng Việt 和简体中文
