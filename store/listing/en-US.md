## Description

Claude Local Session Manager is an unofficial desktop utility for people who use
Claude Code and Claude Desktop on Windows. It finds the session files those apps
keep on your computer and shows them in one fast, searchable list — with clear
titles, projects, dates, sizes and the exact files behind each session.

Everything happens locally. The app has no account and no server, sends no
session content anywhere and collects no telemetry.

Cleaning up is designed to be safe:
• The app always starts in Safe Mode, where nothing can be deleted.
• Permanent deletion must be armed for the current session by typing
  ENABLE DELETE, and turns itself off after one delete or 10 minutes.
• Every delete shows an exact plan of the files that will and will not be
  removed, and requires a typed confirmation.
• Sessions that are open in Claude Code, or while Claude Desktop is running,
  cannot be modified.
• Your project folders are never touched.

Unofficial local utility. Not affiliated with, endorsed by or sponsored by

## Product features

- Finds Claude Code and Claude Desktop sessions automatically
- Fast search by title, prompt, project, path or session ID
- Group by date or project; sort by date, title or size
- Details: titles, IDs, model, message counts, files and sizes
- Archive / Restore Claude Desktop sessions
- Hide sessions in the manager without changing Claude's files
- Export as JSONL, JSON or readable Markdown
- Safe Mode by default; armed, one-shot permanent delete with an exact plan
- Storage overview: largest projects and sessions
- English, Tiếng Việt and 简体中文 interface
