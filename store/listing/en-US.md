## Description

LHP Local Session Manager is an unofficial, independent desktop utility for
Windows. It finds the session files that Claude Code and Claude Desktop keep on
your computer and shows them in one fast, searchable list, with clear titles,
projects, dates, sizes and the exact files behind each session.

Everything happens locally. The app has no account and no server, sends no
session content anywhere and collects no telemetry.

What you can do:
• Browse and inspect local sessions: title, project, model, message counts,
  files and sizes.
• Search and organize your session history by title, prompt, project, path or
  session ID. Group it by date or project.
• Export a session as JSONL, JSON or readable Markdown.
• Hide sessions in the manager without changing any session file.
• Safely remove local transcript-only sessions, with a protected delete plan.
• See which projects and sessions use the most disk space.

Cleaning up is designed to be safe:
• The app always starts in Safe Mode, where nothing can be deleted.
• Permanent deletion must be armed for the current run by typing
  ENABLE DELETE, and turns itself off after one delete or 10 minutes.
• Every delete shows an exact plan of the files that will and will not be
  removed, and requires a typed confirmation.
• Sessions that are open in a running program cannot be changed.
• Your project folders are never touched.

Limits of the Microsoft Store edition:
Sessions that have Claude Desktop metadata can be viewed and exported, but not
archived, restored or deleted. Windows Store packaging isolates certain AppData
writes, so this edition does not change Claude Desktop's data.
